# Мнемозина Кино

Small personal web app for iPhone: mark watched episodes and see new ones.

- Code only. No personal data is stored here.
- Data lives in the owner's Yandex Disk app folder; the app asks for access to that folder only (`cloud_api:disk.app_folder`).
- Opens at https://nevaknight.github.io/OBSIDIAN_WEB_UI_MOVIE/ — in Safari: Share → Add to Home Screen.
